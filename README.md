# omkit-go

Multi-tenant SaaS scaffolding for Go services. Pooled Postgres with RLS, Valkey eventbus, BYOK secrets, LLM provider abstraction, observability middleware, and tenant-scoped job queues.

```go
import "github.com/omurlabs/omkit-go/dbpool"
```

Status: v0.1.0 — internal API stable. Public documentation pending.
