# Code of Conduct

This project follows the [Contributor Covenant 2.1][cc].

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Our pledge

We — contributors and maintainers — pledge to make participation in
this project a respectful and productive experience for everyone,
regardless of background or identity.

## Our standards

Examples of behaviour that contributes to a positive environment:

- Showing empathy and patience toward other contributors.
- Being open to constructive feedback and giving feedback gracefully.
- Focusing on what is best for the project and its users.
- Using clear, professional language in issues, PRs, and reviews.

Examples of unacceptable behaviour:

- Personal attacks, insults, or political attacks.
- Public or private harassment.
- Publishing others' private information without explicit permission.
- Other conduct which could reasonably be considered inappropriate
  in a professional setting.

The full list of expected and unacceptable behaviours, along with
enforcement guidelines, lives in [Contributor Covenant 2.1][cc].

## Scope

This Code of Conduct applies in all project spaces — issues, pull
requests, discussions, code review, and any direct communication
related to the project — and when an individual is officially
representing the project in public spaces.

## Reporting

If you experience or witness behaviour that violates this Code, report
it privately to the maintainers. The fastest channel is a
[GitHub Security Advisory](https://github.com/omurlabs/omkit-go/security/advisories/new)
with a brief note that this is a Code of Conduct report rather than
a security vulnerability — that path keeps the report private and
delivers it to the maintainer team without exposing the reporter.

If a Security Advisory is not appropriate, email
`vadim+omkit-coc@yuzi.co` with subject `[omkit-go CoC]`.

We will review and respond to every report. Reporters will not be
named in any public follow-up without their explicit consent.

## Enforcement

Project maintainers will follow the
[Contributor Covenant 2.1 enforcement guidelines][cc-enforcement] —
correction, warning, temporary ban, permanent ban — applied
proportionally to the severity and pattern of the behaviour.

[cc-enforcement]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines

Maintainers who do not follow or enforce this Code of Conduct in
good faith may face temporary or permanent consequences as
determined by other members of the project's leadership.
